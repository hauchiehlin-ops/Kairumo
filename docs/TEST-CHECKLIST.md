# 實機測試清單 · v2.7.0

> 這裡只列**模擬器驗不了、需要真實裝置才成立**的項目。
> 每一項都寫成可以當場判定的條件 —— 沒有「大致可用」這種說法。
> 自動化測試已覆蓋的部分（core 942、Apple 306 + 5 UI、Android 200）不重複列。

安裝方式：
- Apple：Xcode 開 `apple/Kairumo.xcodeproj`，選你的裝置執行
- Android：`cd android && ANDROID_HOME="$HOME/Library/Android/sdk" ./gradlew :app:installDebug`

## 回報方式

有問題的話，附上：

1. **哪一項編號**（例如 H2）
2. **畫面截圖** —— Android 的診斷列會顯示工具類型、接觸半徑、壓感、密度與仲裁結果，一張圖就夠我判斷
3. **版本號** —— Mac 視窗左上角，或 Android 的「系統診斷」

Android 想看更詳細的錯誤時：

```bash
adb logcat -d -s AndroidRuntime:E
```
