# ADR-0001：統一時間軸

- 狀態：**已接受**（2026-09-12）
- 相關：`format-spec.md` §4、`features.md` C1/C4/A10/B6

## 背景
市調顯示 Notability 的「點筆畫跳回當時錄音」是課堂/會議場景唯一無可取代的功能，
而 Goodnotes 完全沒有錄音。Padnote 要同時做好手寫與錄音，兩者的時間關係必須是
資料模型的一等公民。

## 決策
所有帶時間的內容（筆畫、文字編輯、錄音 session、轉錄詞）一律以單一
`notebook_time_us: u64` 座標系定位，原點記於 manifest 的 `time_origin_unix_us`，
取樣自 monotonic clock。

轉錄詞的時間戳記在**筆記本時間軸**上，而非音檔內偏移。

## 理由
- 「某筆畫當時在錄什麼」退化為區間查詢，而非跨子系統的時間換算
- 轉錄詞用筆記本時間軸 ⇒ 使用者剪輯或合併錄音後，對應關係仍成立
- A10（筆跡重播）與 B6（版本回溯）幾乎免費取得

## 後果
- **必須在 M0 定稿**。時間軸語意事後變更 = 所有既有筆記的時間資料失效。
- 所有子系統都依賴 `padnote-doc`，形成核心相依點（已接受）。
