# ADR-0003：接受非開源系統 API 作為手寫辨識後端

- 狀態：**已接受**（2026-09-12）
- 相關：`architecture.md` D2、缺口 #1

## 背景
專案原則是全開源。但開源的線上（筆畫序列）中文手寫辨識模型**實質上不存在**，
可用的訓練資料（CASIA-OLHWDB、SCUT-COUCH）多為學術研究授權，商用受限。

## 決策
接受 Apple Vision 與 ML Kit Digital Ink 作為 HWR 後端的明示例外。
以 `HwrEngine` trait 隔離，保留 `OcrFallback`（100% 開源）與 `SelfHosted`（P3）。

## 理由
- 兩者皆為**純裝置端、免費、免申請 API key**，不引入伺服器依賴，不違反「無後端」
- HWR 在架構上是**可選增強**：即使完全不可用，手寫／打字／錄音轉文字三大核心
  需求仍然成立
- 替代方案（自訓模型）需 6–12 個月與 GPU 預算，會拖垮整個時程

## 後果
- 純開源建置只能使用 `OcrFallback`，品質明顯較差（已於文件揭露）
- 「引擎與權限中心」(I1) 須顯示目前使用的後端與其開源狀態，讓使用者知情
