# 圖學學習工具計畫（2026-10-06 起）

對象：大學「工程圖學」課。依 CNS／ISO 128 的畫法（兩者在投影、線型、尺寸標註上一致；標題欄欄位用中文）。
約束不變：完全免費、開源、不建後端、本地優先、**兩個平台行為一致**、六語介面。

## 設計原則

- 幾何一律在核心（Rust），兩個平台只畫與收手勢 —— 與現有立體輔助、圖學範例同一個模式。
- 核心輸出 `Role + 折線`（與 `FfiSheetStroke` 同形），平台用現有的「插入圖紙放在視野中央並自動套索」流程落地，不另發明一條路。
- 所有新字串走 `i18n/ui-strings.json`（六語），無障礙名稱一併補。
- 每個核心功能都有單元測試；兩個平台各有 UI／整合測試與模擬器實測。
