# 支持 Kairumo

Kairumo 是免費的、開放原始碼的（Apache-2.0），**沒有帳號、沒有伺服器、不追蹤任何東西**。
這不是行銷話術，是架構決策：你的筆記留在你自己的裝置上，同步走你自己的雲端硬碟。

## 這個專案每年花多少錢

| 項目 | 費用 |
|---|---|
| Apple 開發者帳號（上架 iOS / iPadOS / macOS 的唯一必要支出） | US$99／年 |
| Google Play 開發者帳號 | US$25 一次性 |
| 伺服器 | **US$0** |
| 語音模型託管 | **US$0** |
| 說明文件與隱私權政策的網址 | **US$0** |

**大約一百美金。** 沒有訂閱制、沒有廣告、沒有付費解鎖 —— 因為為了一百美金
去建立一個要長期維運、要負資料外洩責任的收費系統，代價與收益完全不成比例，
而且會毀掉這個 App 唯一真正的差異化：免費、無帳號、無伺服器。

## 如果你想幫忙

**捐贈**：連結在 GitHub 專案頁的「Sponsor」按鈕（設定好之後會出現）。
一百美金的目標，少少幾個人就夠了。

**但更有用的是這些：**

- **回報問題**，附上版本號（Mac 視窗左上角、Android 的「系統診斷」裡都看得到）
  與重現步驟。實機上才會出現的問題我們在模擬器上看不到。
- **實機測試**。專案裡有一批只有真實裝置才驗得了的項目（掌拒、筆尖延遲、
  跨裝置同步、在 Goodnotes 裡繼續編輯匯出的 PDF），列在 `docs/TODO.md`。
- **翻譯校對**。介面有六國語系、五百多條字串，其中不少是機器能翻但母語者
  一看就知道不對的那種。

## 不會做的事

- 廣告
- 賣使用者資料
- 把關鍵功能閉源後再收費

這三項不是「目前沒做」，是**不會做** —— 記在 `docs/plans/sustainability-evaluation.md`，
免得以後重新討論。
